# Data-Structure-Lab-Practicals

This repository contains practical programs for the Data Structures Lab. Each experiment demonstrates the implementation of various data structure concepts using C++ (and Java for one experiment). The programs are designed to help students understand and apply fundamental data structure techniques.

## Experiments

Below is a list of experiments included in this repository:

1. **Experiment 1**: Implementation of a tree structure to represent a book hierarchy (chapters, sections, subsections).
2. **Experiment 2**: Implementation of stack operations using arrays.
3. **Experiment 3**: Implementation of queue operations using arrays.
4. **Experiment 4**: Implementation of linked lists (singly, doubly, and circular).
5. **Experiment 5**: Polynomial addition using linked lists.
6. **Experiment 6**: Representation of a graph using adjacency matrix and adjacency list.
7. **Experiment 7**: Implementation of Dijkstra's algorithm for shortest path.
8. **Experiment 8**: Implementation of Kruskal's algorithm for minimum spanning tree.
9. **Experiment 9**: Implementation of a sorting algorithm in Java.
10. **Experiment 10**: Implementation of hashing techniques.
11. **Experiment 11**: Construction of an Optimal Binary Search Tree (OBST).
12. **Experiment 12**: Employee management system using index sequential files.

### Prerequisites
- A C++ compiler (e.g., `g++`) for `.cpp` files.
- A Java compiler (e.g., `javac`) for `.java` files.
